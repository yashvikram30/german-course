# German A1 — Curriculum Map (draft v1)

Scope source: Goethe-Zertifikat A1 Start Deutsch 1 (word list + Prüfungsziele). All lessons, sentences and exercises are to be written originally; the Goethe list is used only as a scope reference.

Targets: ~650 words (≈54 per unit, half to be active), 12 units × 3 lessons, 1 review lesson + 1 unit test per unit, 1 final mock exam.

## Design rules

1. **Situation first.** Every lesson opens with a short dialogue or text (with audio) in a real-life situation, as in Menschen/Netzwerk/Studio d.
2. **Grammar serves the task.** A grammar point is introduced only when the situation needs it. Explanations are in English, book style: rule, table, 3–5 examples, common mistakes.
3. **Chunks before rules.** Fixed phrases (Wie geht's? Ich möchte…) appear before the grammar behind them is explained.
4. **Nouns always with article and plural.** Vocabulary is stored as `der Tisch, -e`, never bare. Gender is colour-coded (der blue, die red, das green).
5. **Recycle.** Each unit reuses at least 30% of earlier vocabulary and grammar via spaced repetition.
6. **Grammar scope is capped at the A1 list.** Perfekt only for the ~15 listed verbs, Präteritum only haben/sein, Genitiv only names, Konjunktiv II only möchte / würde gern.

## Lesson template (all 36 new lessons)

1. **Situation** — dialogue/text + audio, 4–6 comprehension questions
2. **Wortschatz** — 8–12 new words with image/example sentence, gender colour-coded
3. **Grammatik** — one point, rule box + table + examples + "watch out"
4. **Übungen (guided)** — 6–8 controlled exercises (gap-fill, matching, multiple choice, word-order tiles)
5. **Übungen (free)** — 1–2 production tasks (type a reply, short writing, speaking prompt)
6. **Kulturtipp** — 3–4 sentences of real-life context (Sie vs du, Sonntag closing, deposit bottles…)
7. **Zusammenfassung** — 5-line recap and "Can you…?" checklist

Review lesson (L4): mixed retrieval from the whole unit plus 30% from earlier units. Unit test: 25 points across the four exam skills (see below).

## Exercise types

| Type | Trains | Notes |
|---|---|---|

| Gap-fill (type) | grammar, spelling | accept ä/ae, ö/oe, ü/ue, ß/ss with a hint |

| Matching | vocab | word↔image, question↔answer |

| Case choice | cases | pick the correct article form |

| Short writing | writing | form fill-in, 20–30 word message, self-check checklist |

Every exercise carries tags: `skill` (listening, reading, writing, speaking), `area` (grammar, vocab, pronunciation, culture), `topic` (e.g. akkusativ, time), `unit`, `difficulty`.

## Test design

- **Quiz** (after each lesson): 5 items, no stakes.
- **Unit test**: 25 points, mirrors exam skills. Hören 6, Lesen 6, Schreiben 6, Sprechen (self-rated) 3, Grammar/Vocab 4. Pass mark 70%; below that, the app suggests specific review lessons by tag.
- **Mock exams** (after unit 12): four full Modelltests (the separate Prüfung section of the app) reproducing the real Start Deutsch 1 format and timing: Hören ~20 min (3 Teile, 15 items), Lesen 25 (3 Teile, 15 items), Schreiben 20 (form 5 + message 10), Sprechen 15 (3+6+6). Each part is 15 raw points; raw × 1.66 gives the official 100-point scale, pass at 60. Source: Goethe-Institut Durchführungsbestimmungen, 1 Sept 2025.
- **Diagnostic**: failed items are tagged and fed back into the review queue.

## Gamification layer (tied to learning, not volume)

- **Daily goal** (5/10/15 minutes) with a **streak**; one **freeze** per week.
- **XP** earned only on first completion and on correct reviews, with a daily cap, so grinding earns nothing.
- **Spaced repetition**: every word, grammar pattern and phrase becomes a card with intervals 1d → 3d → 7d → 16d → 35d; wrong answers drop the card back a step.
- **Mastery levels** per word and per grammar topic (new → learning → known → mastered).
- **Progress map**: units as nodes on a path; unit "boss test" unlocks the next unit (soft lock: the next unit can still be previewed).
- **Badges** for real milestones: first 100 words, a full unit, 7-day streak, perfect test, all cases correct 20 in a row.
- **Focus mode**: choose Grammar / Vocab / Listening / Reading / Writing and get a session drawn only from those tags.
- Not included in v1: leaderboards, lives/hearts, paywalled hints.

## Data model sketch

```
Unit      { id, title, theme, order, goals[] }
Lesson    { id, unitId, order, type: new|review|test, situation, grammarIds[], vocabIds[] }
Vocab     { id, lemma, article, plural, pos, translation, example, audio, unitId, tags[] }
Grammar   { id, title, explanation(md), table, examples[], unitId }
Exercise  { id, lessonId, type, prompt, answers[], explanation, tags{skill, area, topic}, difficulty }

Progress  { userId, lessonId, score, completedAt }
```

Content lives as JSON/Markdown files in the repo so it can be written and edited without touching code.

## Build phases

1. **Phase 0** — scaffold web app, content schema, one finished sample lesson (Unit 1, Lesson 1) end to end.
2. **Phase 1** — lesson player (all exercise types), progress storage, units 1–3.
3. **Phase 2** — spaced repetition, streaks and XP, review sessions, units 4–6.
4. **Phase 3** — tests, focus mode, progress map, units 7–9.
5. **Phase 4** — audio (text-to-speech or recorded), speaking prompts, units 10–12 and the mock exam.
6. **Later** — A2 content pack, stats dashboard, export/backup.
